## 3. 组件树

```
app.py (main)
├── st.title("CareerMatch Agent")
├── st.caption("上传简历 + 粘贴 JD，3 分钟获得完整匹配报告")
│
├── st.columns(2)
│   ├── col1 (左侧 — 输入区)
│   │   ├── st.file_uploader("上传简历", type=["pdf"])
│   │   ├── [if uploaded] st.info(简历解析预览)      ← parse_resume() 结果
│   │   └── [if uploaded] st.expander("查看解析详情")
│   │
│   └── col2 (右侧 — JD 输入)
│       ├── st.text_area("粘贴 JD", height=200)
│       └── [if pasted] st.info(JD 解析预览)        ← parse_jd() 结果
│
├── st.checkbox("同时生成求职信（可选）")
│
├── st.button("🔍 开始分析")
│   └── disabled = (not resume_ready) or (not jd_ready)
│
├── [if analyzing] st.status("分析中...")
│   ├── 逐步骤更新 status text
│   └── st.progress(completed / total_steps)
│
├── [if done] st.markdown(render_report(report))     ← 完整报告
│
├── [if done] st.download_button("下载报告 (.md)")
│
└── [if error] st.error(用户友好错误信息)
    └── [if warning] st.warning(用户友好警告信息)
```

## 5. 设计决策速查

| 决策 | 理由 | 出处 |
|------|------|------|
| 两栏布局（输入 | 报告） | 用户对照 JD 看报告，不需要来回滚动 | PRD §11.2 |
| 报告在同页渲染，不跳转 | 保持用户上下文，方便对比修改输入 | PRD §11.2 |
| 点击"开始分析"前先解析 | 避免跑了 50s 发现简历解析错了 | PRD §11.2 |
| 分析进度按 ReAct 轮次更新 | 用户知道在做什么，不是干等 | PRD §11.3 |
| 求职信默认不打勾 | P2 功能，不自动触发，用户主动选 | AGENT_DESIGN.md |
| 错误信息用中文，不展示 traceback | 目标用户是求职者，不是开发者 | PRD §11.3 |
| 下载为 .md 而非 .pdf | 用户可自行编辑报告、复制片段投递 | PRD §11.3 |
